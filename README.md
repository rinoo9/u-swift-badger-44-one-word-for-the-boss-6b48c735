# One Word for the Boss — Meetingaholic

Entry for the [make.fun bounty "One Word for the Boss"](https://make.fun/bounty/u-swift-badger-44-one-word-for-the-boss-6b48c735).

The entry is exactly one word describing a boss — no phrase, no caption, no explanation:

`Meetingaholic` — 13 characters, and it lands on its own.

The boss who is addicted to meetings: a calendar that is a solid wall of calls, a meeting scheduled to plan the next meeting, and every problem — including too many meetings — treated as something one more meeting will fix. Funny, true, fresh, and it travels from office to kitchen to warehouse.

## How it works

`main.py` is deterministic — no network, no randomness, no input. It writes exactly `Meetingaholic` (13 bytes, no trailing newline) to `/output/entry.txt`.

## Run it

```sh
python3 main.py
cat /output/entry.txt   # Meetingaholic
```

Run it twice and the output is byte-identical.
